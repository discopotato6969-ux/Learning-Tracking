# Website audit — 2026-09-30

Scope: source review, production build/type validation, ESLint, local authenticated HTTP checks, and browser verification of the login page. This is not a completed cross-browser, mobile accessibility or third-party video playback audit.

## Resolved and verified

- Existing proxy relocation to `src/proxy.ts` works: unauthenticated `/`, `/api/progress`, and `/api/youtube/playlist` return 307 redirects to login.
- Production progress rendering fixed in `src/lib/progress-store.ts`: `await connection()` sits outside the file-read catch so prerender interruption is not swallowed. The six dependent routes are dynamic in the successful build. A completion write changes production lesson HTML without rebuilding; original progress was restored.
- Authenticated dashboard, catalog, favorites, progress and Python course detail return 200. Login returns 200 with configured credentials.

## Important distinctions

- A cookie without Max-Age/Expires is a browser session cookie, not automatically a permanent cookie. The stronger issue here is that the signed token itself never expires and remains reusable after logout.
- Source-confirmed concurrency and UI state risks above were not stress-tested against user data.
- Playback availability, YouTube quota behavior, actual playlist selection/resume, mobile layout, and full keyboard navigation remain unverified. Missing API configuration blocks a complete playlist audit.
- No credentials were included in this report, no third-party content was modified, and unrelated application defects were not changed during the audit.
